# hello-world

A self-contained Flappy Bird clone built with HTML5 Canvas and vanilla JavaScript — no libraries, frameworks, or build tools.

## How to run

Open `index.html` in any modern browser (double-click the file, or drag it into a browser window). No server is required.

## How to play

- **Space** / **Up Arrow**, **click**, or **tap** the screen to flap.
- Fly through the gaps between the pipes; each pipe pair you pass scores one point.
- Hitting a pipe, the ground, or flying off the top ends the game.
- Press Space or tap to start, and again to restart after a game over.
- Your high score is saved in the browser via `localStorage`.

## Files

- `index.html` — the entire game (markup, styles, and game logic).
